# Inventory Management System

A lightweight C# console application I built to practice basic CRUD operations and data structures. It's a simple, interactive CLI (Command Line Interface) tool designed to help you keep track of product stock.

## Features
* **Add Products:** Easily add new items with their name, price, and initial quantity.
* **Update Stock:** Quickly modify the stock levels of existing products.
* **View Inventory:** Display a clean, formatted list of all items currently in stock.
* **Remove Items:** Delete products entirely from the system.
* **Input Validation:** Prevents crashes from invalid user inputs (like typing letters instead of numbers).

## Tech Stack
* C#
* .NET Console App

## How to Run
Simply clone the repo and open the `.csproj` file in Visual Studio, or run it via the .NET CLI using:
`dotnet run`
